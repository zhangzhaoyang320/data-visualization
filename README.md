# Data Visualization Platform

A web-based data visualization tool built with Streamlit and Plotly.

## Features

- Upload Excel files and auto-generate interactive charts
- Support bar, line, pie, and scatter charts
- Real-time data preview and statistics

## Tech Stack

- Python
- Streamlit
- Pandas
- Plotly

## How to Run

```bash
pip install streamlit pandas plotly openpyxl
streamlit run app.py
```

## Demo

Upload any `.xlsx` file and select chart type from the sidebar to visualize your data.
